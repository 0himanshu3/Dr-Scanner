Dr Scanner
Dr Scanner is a tool that scans images and converts them into scanned PDFs. It enhances document clarity and is fast and efficient.

Dr_Scanner_v2 allows text searching, text-indenfication in scanned pdf as well as extract the texts from the doc.



Additional Note->
To use the EasyOCR(deep learning) model to Recognize text just change the scanner file in main
Result of both model are present provided
